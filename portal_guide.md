# Как пользоваться порталами (Multiverse Portals)

Краткий гайд для игроков.

Есть **три режима**: локальные (шерсть), межсерверные (`[Multi]` / `[To]` / `[Pair]`) и **Away** (другой биом на этом же сервере).

**Языки:** [English](portal_guide.en.md) · [中文](portal_guide.zh.md) · [Русский](portal_guide.md)

---

## Локальные порталы (шерсть)

Как ColorPortals — телепорт **в пределах этого сервера** (можно в другой мир).

1. Рамка из **шерсти одного цвета** — любое замкнутое кольцо (маленькая дверь 3×4 — только пример)
2. **Настенная табличка** на правой стойке (если смотреть на портал)
3. **1-я строка** — имя, **2-я** — канал (число `0`–`9999`)

Порталы с **тем же цветом и каналом** связываются в кольцо: A→B→C→A. Два портала = туда-обратно.

Зайди в **фиолетовый проём**. Плита не нужна (если уже стоит — тоже сработает). Кнопка под табличкой по желанию. ПКМ по табличке — инфо. Список: `/mvp local list`.

---

## Away — другой биом (этот сервер)

Как портал в Ад, но между **биомами верхнего мира** на этом сервере.

1. Рамка из **блока этого биома**: дуб в лесу, песчаник в пустыне, плотный лёд на леднике и так далее. Любое замкнутое кольцо; **настенная табличка** на правой стойке
2. **1-я строка** — `Portal` / `Портал`. **2-я** пустая или `Away` / `Авей`
3. Зайди в **фиолетовый проём**

Первый проход привязывает к одному биому (океан и пещеры тоже; Ад и Край нет) и держит связь, как портал в Ад. Плагин может сам поставить маленькую обратную рамку из материала **твоего** биома, табличка справа. Если рамка из не того блока — в чате напишет, какой нужен здесь.

Если на 2-й строке `Random` — это **межсерверный** портал, даже на дубе. Away **не** показывается на публичной карте.

## Межсерверные порталы

## Собрать портал

1. Рамка как у адского портала — проём **2×3** (воздух), вокруг любой твёрдый блок. Можно и **большой замкнутый круг** — пока кольцо целое, внутри горит ванильная текстура портала в Ад; разомкнул — материя гаснет.

```
O O O O
O . . O
O . . S
O . . O
O O O O
```

`O` = рамка, `.` = воздух, `S` = табличка на правой стойке.

2. На **правую стойку** рамки повесь **табличку** (если смотреть на портал).
3. На **1-й строке** таблички напиши тип (регистр не важен). Плита не нужна — зайди в фиолетовый проём.

Рамка должна быть **замкнута**. Сломанная табличка у Random/Away снимает портал целиком.

## Типы на 1-й строке

| 1-я строка | Что делает |
|------------|------------|
| `[Multi]` / `[mvp]` / `[portal]` / `[Random]` / `Портал` / `传送门` | Случайный сервер (линк **закрепляется**) |
| `[To]` / `К` / `На` / `前往` | Конкретный сервер: **IP + порт** (2-я / 3-я строка) или id из каталога |
| `[Pair]` / `Пара` / `配对` | Парный портал туда-обратно |
| `Portal` / `Портал` / `传送门` на рамке из **материала этого биома** | Away — другой биом на этом же сервере (или напиши `Away` / `Авей` / `异界`) |

Away: подробности в разделе [Away](#away--другой-биом-этот-сервер) выше.

### Связать два своих сервера (админ)

Подробная инструкция в [README.ru.md](README.ru.md#связать-два-своих-сервера-туда-обратно). Кратко:

1. **Лучший вариант:** на Alpha табличка `[Pair]` → скопировать код → на Beta `[Pair]` + код во 2-й строке.  
2. **Через IP:** `Portal` / `1.2.3.4:25565` (или только адрес, если порт `25565`) — каталог не нужен.  
3. **Через id:** Alpha `[To]` / `beta`, Beta `[To]` / `alpha` (id из `/mvp info`).  
4. Для id оба сервера должны быть в публичном каталоге [mp.mvse.ws](https://mp.mvse.ws/) (нужны `accept-transfers=true` и адрес, доступный из интернета; `public-host` обычно берётся из `server-ip`).

English: [README.md](README.md#link-two-of-your-servers-round-trip) · 中文: [README.zh.md](README.zh.md#两台服互通往返) · Русский: [README.ru.md](README.ru.md#связать-два-своих-сервера-туда-обратно)

### Random = sticky

1. Ставишь `[Multi]` → белые частицы → портал **привязывается к одному серверу**.
2. Пока табличка на месте — всегда туда (и после рестарта сервера тоже).
3. Хочешь другой сервер — поставь **кнопку у таблички** и нажми её: это **ручка двери**, как в аниме *Ходячий замок* — переключает, куда ведёт портал (сначала по знакомым MVP-серверам, иначе новый random).
4. Или **снеси табличку** и поставь `[Multi]` заново.
5. Ручка **не работает** на `[To]` (фиксированный адрес) и `[Pair]`.
6. Если цель временно лежит — линк **не меняется**; попробуй позже, крутани ручку или пересоздай табличку.

## Как войти

Зайди в **фиолетовый проём** (не стой на верхней перекладине рамки). Плита рядом по желанию — тоже сработает. Подожди заряд — тебя перекинет.

## Согласие на one-way (`/mvp ready`)

Есть два вида переходов:

- **С возвратом** — парный `[Pair]` или сервер с тем же плагином. Заходишь **свободно**, согласие не нужно.
- **В одну сторону** — случайный публичный сервер из сканера. Обратно этим порталом не вернуться.

Перед one-way **один раз** разреши:

```
/mvp ready
```

или просто в чат:

```
mvp ready
```

Снять согласие:

```
/mvp ready off
```

или в чат: `mvp ready off`.

## Входящий трафик (для админа)

На сервере-приёмнике можно отсеивать приток:

```
/mvp ingress           — лимиты
/mvp deny add Nick …   — в бан порталов
/mvp rep Nick -50      — штраф к репутации
```

Подробнее: [README.ru.md](README.ru.md).

## Нагрузка на сервер (для админа)

Плагин **не «тяжёлый» постоянно**, но и не «нулевой» как маленький utility. В фоне почти всё async; **пики** — при создании `[Multi]` (Scan… + пробы), при зарядке в проёме и если много порталов с визуалом.

| Что | Когда | Насколько |
|-----|--------|-----------|
| Сканеры (MineScan + Cornbread) | раз в ~1–2 мин | HTTP + SQLite — **TPS почти не трогают** |
| Bind при создании `[Multi]` | один раз | пробы по сети в фоне — **до ~90 с** |
| Переход после bind | стоишь в проёме | ~2 с charge + transfer, **без долгого поиска** |
| Частицы «материи» | каждые 0.5 с | только если игрок **ближе ~20 блоков** |
| Локальные wool-порталы | вход в проём | **очень лёгко** |

**Слабый VPS (1–2 GB RAM):** нормально как **сервер-приёмник** с 1–2 привязанными `[Multi]`. Не ставь десяток порталов с эффектами и не пересоздавай таблички без нужды.

**Урезать нагрузку** — в `config.yml`:

```yaml
scanner:
  refresh-seconds: 180
  sample-count: 20
  max-attempts: 10
  bind-search-seconds: 45

effects:
  matter:
    enabled: false      # или particles: false

registry:
  enabled: false   # так и оставляй — открытый каталог по HTTPS
```

Самый лёгкий режим: только **PAIR** или только **локальная шерсть**. Подробная таблица — [docs/TECHNICAL.md](docs/TECHNICAL.md#performance--weak-servers).

## Вещи

- Перенос инвентаря **по умолчанию выключен**. Админ включает: `/mvp settings export on` / `import on` (или `/mvp items …`).
- На **публичный one-way** — вещи **остаются у тебя** в инвентаре (их не забирают).

## Версии

В игре: **`/mvp version`** — какая версия стоит и какая свежая на mp.mvse.ws.

Плагин не кидает на сервер, куда твой клиент не зайдёт. Если целей нет — «нет совместимых серверов».

Скачай jar с [mp.mvse.ws](https://mp.mvse.ws/) — в имени файла указана версия (`MultiversePortals-1.2.1.jar`).

## Админу: `accept-transfers` и каталог

В **`server.properties`** (не в плагине):

```properties
accept-transfers=true
```

Без этого Minecraft **отклоняет** вход по Transfer — гости с других миров не зайдут. Плагин тогда работает в **локальном режиме** (шерсть, Pair/`[To]` по IP) и **не публикуется** на mp.mvse.ws.

Адрес для Transfer плагин берёт из `server-ip` / `server-port` сам. В `config.yml` задай `public-host` / `public-port`, если игроки заходят по **другому домену или порту** (Docker `-p 25566:25565`, NAT, прокси) — иначе в каталог уйдёт внутренний `25565` / LAN IP и сервер останется local-only. Проверка: `/mvp settings`.

## Частые проблемы

| Сообщение | Что делать |
|-----------|------------|
| Нужен `/mvp ready` | Напиши `/mvp ready` или `mvp ready` в чат |
| Нет совместимых серверов | Подожди / другая версия клиента; админ: `/mvp scanner` |
| Не удалось найти живой сервер | Зайди в проём ещё раз |
| Парный портал сломан | Нужно связать пару кодом `[Pair]` |
| Сервер не в каталоге | `accept-transfers=true`, публичный IP/домен (не Docker `172.*`), **`public-port` = наружный порт**; см. `/mvp settings` → catalog |

## Команды игрока

```
/mvp ready          — разрешить one-way
/mvp ready off      — запретить one-way
/mvp local list     — локальные шерстяные порталы
/mvp help           — справка
/mvp scanner        — сколько серверов в пуле (инфо)
```

Админ: `/mvp settings` (карта / гости / инвентарь / кто создаёт / типы порталов).

В `config.yml` по умолчанию включены все типы (`away`, `wool`, `multi`, `pair`, `to`). Отключить любой: `portals.types.multi: false` или `/mvp settings type multi off`. Кто строит порталы: `portals.create: everyone` (все игроки) или `admin` (только OP / `multiverseportals.admin`).

Полная инструкция для админов: [README.ru.md](README.ru.md) · [README.md](README.md) · [README.zh.md](README.zh.md).
